3. Checksums & Integrity Verification

Always verify your downloaded ISO file to ensure it wasn't corrupted during transfer.

  • Official Checksum Source: Get the official cryptographic checksum files directly from the Debian CD Image Directory (look for SHA512SUMS).

How to check your download via command line:

Open your terminal in the folder where you downloaded your ISO and run the matching command:

For Linux / macOS:

sha512sum debian-13.7.0-amd64-netinst.iso

For Windows (PowerShell):

Get-FileHash -Path "debian-13.7.0-amd64-netinst.iso" -Algorithm SHA512

Compare the resulting long string of characters against the matching line inside the official SHA512SUMS file. If they match completely, your ISO is safe and intact!
