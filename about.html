About Linux ISO Verifier

Linux ISO Verifier is a free browser-based utility for calculating SHA-256, SHA-512, SHA-1, and MD5 checksums of Linux ISO images and other local files. You can compare a calculated checksum with a value supplied by a distribution or software publisher.

Purpose

The tool is intended to make it easier to check a downloaded image for accidental corruption before using it. Hash comparison is not a substitute for verifying signatures or following the publisher's security instructions.

Who operates this site

This independent project is maintained by everydaylinuxuser on GitHub. It is not operated by or affiliated with any Linux distribution or the organizations that publish Linux images. The source project is available on GitHub.
